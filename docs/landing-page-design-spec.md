AutoApply Landing Page — Complete Frontend Specification
Overview
AutoApply is a single-page SaaS landing page for a job application automation platform. The entire design follows a premium, dark-themed, Apple-inspired aesthetic with glassmorphism (frosted glass effects), smooth scroll-reveal animations, purple/blue gradient accents, and interactive UI components. The page is built as a single HTML file. The font used throughout the entire site is "Plus Jakarta Sans" from Google Fonts, loaded in weights 300, 400, 500, 600, 700, and 800. A secondary monospace font "JetBrains Mono" (weights 400 and 500) is used for stats, prices, dates, and code-like elements. The custom easing curve used for nearly all transitions and animations is cubic-bezier(0.16, 1, 0.3, 1).
Color System
The page background is #060608, which is a near-black with a slight blue tint. Card backgrounds use #0d0d12, and card hover states use #12121a. All borders throughout the page are white at varying opacities: subtle dividers use rgba(255,255,255, 0.04), card borders use rgba(255,255,255, 0.07), and hover-state borders use rgba(255,255,255, 0.12). Primary text is #f0f0f5 (near white), secondary text is #8a8a9a (medium gray), and muted/tertiary text is #55556a (dark gray).
The accent colors are: primary purple #7c5cfc, light purple #a78bfa, blue #5b8dff, green #34d399, and cyan #22d3ee. The main gradient used for buttons and icon backgrounds is linear-gradient(135deg, #7c5cfc, #5b8dff). A three-color gradient linear-gradient(135deg, #7c5cfc, #5b8dff, #22d3ee) is used for gradient text effects. Gradient text is achieved by applying this gradient as a background, then using background-clip: text and -webkit-text-fill-color: transparent. This gradient text technique is used extensively throughout the page for emphasis words in headings like "Fully Automated," "We're fixing it," "in under 3 minutes," and so on.

The hero H1 uses clamp(3rem, 5.5vw, 4.5rem) at weight 800 with letter-spacing -0.045em and line-height 1.02. Feature card titles are 1.3rem weight 700. How It Works card titles are 1.15rem weight 700. Body text and descriptions range from 0.88rem to 0.92rem at weight 400–500 with line-height 1.55–1.65. Section pill labels are 0.7rem uppercase with weight 600 and letter-spacing 0.1em. Small labels throughout the page (stat labels, badge text, tag text) range from 0.62rem to 0.72rem uppercase with weight 600. Navigation links are 0.8rem weight 400. Primary button text is 0.88–0.92rem weight 600–700.
Layout and Spacing
The max content width for most sections is 1100px, centered with auto margins. The hero section uses a wider 1280px max-width. Standard section padding is 140px vertically and 24px horizontally. Card padding ranges from 36–44px on large cards to 28–32px on smaller ones. Card border-radius is 20–24px for large cards and 12–14px for small elements and buttons. Grid gaps between cards are typically 16–18px. The global easing curve cubic-bezier(0.16, 1, 0.3, 1) is stored as the CSS variable --ease and applied to virtually every transition on the page.

Scroll-Reveal Animation System
Every major element on the page uses a scroll-reveal system. Elements marked with a data-r attribute start with opacity: 0 and transform: translateY(50px). When they enter the viewport (detected by IntersectionObserver with threshold 0.06 and rootMargin '0px 0px -40px 0px'), a "v" class is added which transitions them to opacity: 1 and translateY(0) over 0.9 seconds using the custom easing curve. Once revealed, elements are unobserved. Elements can have additional delay classes: .d1 adds 0.1s delay, .d2 adds 0.2s, .d3 adds 0.3s.
